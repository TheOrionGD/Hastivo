Architecture Topology

Repository Service Boundaries

The platform is structured into eight strictly decoupled directories communicating over verified REST and WebSocket protocols:

frontend/ React 19 + Three.js
Cardless UI philosophy, WebGL 3D avatar viewport, and 7 localized regional languages.
backend/ Node.js Express + MongoDB
REST API Gateway, JWT auth, bcrypt, MongoDB persistence, audit logs, and proxy bridges.
ai-service/ FastAPI + spaCy ISL
Python ISL Subject-Object-Verb (SOV) linguistic reordering and sign sequence synthesizer.
computer-vision/ MediaPipe 21-Joint
Python MediaPipe 21-keypoint hand tracker and real-time gesture classifier.
microservice/ WebSocket + Brevo
Independent duplex WebSocket session broker (port 5002) and notification dispatcher.
showcase/ Telemetry Studio
Live multi-service verification dashboard and cardless interactive test environment.
testing/ Automated Tests
Unified test harness verifying integration compliance across all 8 tiers.
documentation/ Contracts & Specs
Architecture specifications, OpenAPI contracts, and platform operational guides.
End-to-End Pipelines

Certified Workflow Lifecycles

Deterministic, zero-fabricated message flows connecting hearing and Deaf participants:

Workflow 1: Text-to-Sign Pipeline TSOV Grammar
User Input → Frontend → Backend Gateway (5000) → Python AI Service (8000) → ISL TSOV Grammar Engine → Bone Kinematic Sequence → Three.js 3D Avatar Animate.
Workflow 2: Sign-to-Text Pipeline Vision Pipeline
Camera Video Stream → Vision Engine (8001) → MediaPipe 21-Keypoints → Gesture Classification → AI Sentence Synthesis → Web Audio TTS Playback.
Workflow 3: Real-Time Duplex Conversation WebSocket 5002
Speaker (Speech-to-Sign) & Signer (Sign-to-Speech) operate simultaneously over independent WebSocket duplex streams on port 5002 with synchronized state management.
Workflow 4: Moderation & Safety Audit Safety Pipeline
Content Stream → Deterministic Word & Gesture Filter → Severity Scoring → Audit Trail Persistence → Administrative Flagged Telemetry.
